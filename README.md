# Relaydesk — Helpdesk Ticket Management

Relaydesk manages support requests from intake to resolution. Agents create, edit, prioritize, filter and delete tickets using a responsive React interface backed by FastAPI and PostgreSQL.

Original application for the Session 21 DevOps capstone. Infrastructure patterns are informed by the teacher reference; application code and ticket workflow are independently implemented.
